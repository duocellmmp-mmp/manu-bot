## 💡 Estrategia Específica para Binance Spot

### Adaptación de la Estrategia EMA + RSI para Crypto

**El problema:** Las estrategias de SP500 fueron backtestadas en datos diferentes

**La solución:** Ajustar parámetros para BTC

```
PARÁMETROS OPTIMIZADOS PARA BTC:

EMA Rápida:     8 (en lugar de 9)
EMA Lenta:      21 (igual)
RSI:            14 (igual)

Stop Loss:      -5% (en lugar de 15 puntos)
Take Profit:    +10% (en lugar de 25 puntos)

Volumen:        Confirmar expansión
```

### Reglas de Trading Crypto en Binance

```
COMPRA:
1. EMA 8 > EMA 21 ✓
2. RSI entre 30-70 ✓
3. Volumen en expansión ✓
4. Cierre por encima de ambas EMAs ✓

VENTA:
1. EMA 8 < EMA 21 ✓
2. O precio toca TP ✓
3. O precio toca SL ✓
```
