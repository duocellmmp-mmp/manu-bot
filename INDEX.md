## 🆘 Solucionar Problemas

### No veo señales en TradingView
- ✓ Verifica timeframe sea 5 minutos
- ✓ Usa BINANCE:BTCUSDT (crypto) o ES (futuros)
- ✓ Recarga la página (F5)

### El Pine Script no carga
- ✓ Copia el CONTENIDO COMPLETO del archivo
- ✓ Abre Pine Editor en TradingView
- ✓ Nuevo Script → Pega el código

### Backtest diferente a TradingView
- ✓ Normal (comisiones, slippage, horarios)
- ✓ Valida en paper trading antes de operar real
